Define tasks. Declare dependencies. Let the coordinator handle the rest.

Why workgraph?

Dependency Graphs

Tasks depend on other tasks. Complete one, downstream tasks unblock. The coordinator handles the rest.

Service Coordinator

Run wg service start — it spawns agents, detects dead ones, picks up new work. Set and forget.

Agency System

Agents have roles and motivations. Evaluated after each task. Evolved over time. Not generic — specialized identities.

Cycles & Convergence

Write → review → revise loops with structural back-edges. Agents signal --converged when done iterating.

Workflow Functions

Extract proven patterns into reusable templates. wg func extract → wg func apply. Static, generative, or adaptive.

Plain Text, Git-Friendly

Everything in .workgraph/. JSONL graph, TOML config, YAML agency. Human-readable, hackable.

How It Works

Tasks flow through the graph. Complete one, and waiting tasks become ready.

Coordination Patterns

Humans, AI agents, or both — workgraph handles the scheduling.

Service Mode

# Define work
$ wg add "Refactor auth" --skill rust
$ wg add "Update tests" --after refactor-auth --skill testing

# Let the coordinator handle it
$ wg service start --max-agents 4
$ wg tui   # watch it happen

Mixed Human + AI

# Human takes design, service handles the rest
$ wg claim design-api --actor erik
# ... do design work ...
$ wg done design-api

# Service picks up dependent tasks
$ wg service start

Iterative Workflows

# Write → review cycle, max 3 passes
$ wg add "Write draft" --id write \
    --after review --max-iterations 3
$ wg add "Review draft" --id review --after write

# Agent signals when work converges
$ wg done write --converged

Agency

Agents aren't generic. Each gets a role (what it does) and a motivation (how it makes tradeoffs). After each task, performance is evaluated. Over time, roles and motivations evolve — the system learns which identities produce the best work.

$ wg agency init                          # seed starter roles & motivations
$ wg agent create "Careful Coder" \
    --role abc123 --motivation def456
$ wg config --auto-assign true            # coordinator assigns identities
$ wg config --auto-evaluate true          # evaluate after each task
$ wg evolve                               # evolve based on performance

For the theoretical foundations — stigmergy, autopoiesis, cybernetic feedback — see the Organizational Patterns paper.
