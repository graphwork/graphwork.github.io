what is it

A directed acyclic graph of tasks. Dependencies are edges. Completing a task unblocks downstream work. A background service auto-dispatches AI agents to ready tasks.

Plain text storage (.workgraph/graph.jsonl). Git-friendly. No server. No account. Just a binary and a directory.

cycles

Tasks can cycle. Not everything is a straight line.

$ wg add "Run tests" --after push-check \
    --max-iterations 5

$ wg viz
run-tests  (open) ↺ (iter 0/5) ◀────────┐
└→ fix-failures  (open)                   │
  └→ push-check  (open) ────────────────┘

When push-check completes, run-tests re-opens. The whole chain resets. Iteration counter increments. Agents read previous logs and pick up where they left off. Every cycle requires max_iterations. No unbounded loops. Optional guards and delays control when they fire.

recursive prompting

Tasks create tasks create tasks.

Create a task that surveys the codebase, then spawns subtasks for each gap it finds. The coordinator dispatches agents to each subtask. When those complete, evaluation tasks spawn automatically. The whole thing recurses.

$ wg add "Survey codebase for gaps"
$ wg service start --max-agents 4

# survey agent runs, finds 3 gaps, creates subtasks:
$ wg viz

survey-codebase-for-gaps  (done)
├→ fix-auth  (in-progress)  agent-1
│ └→ evaluate-fix-auth  (open)
├→ add-rate-limiting  (in-progress)  agent-2
│ └→ evaluate-rate-limiting  (open)
└→ update-errors  (open)  waiting
  └→ evaluate-errors  (open)

the agency system

Agents have roles (what they do) and motivations (why they do it). They get evaluated after each task. The evolver mutates and crosses over the best performers. Darwinian prompt engineering.

fan-in and fan-out

$ wg viz

hub  (open)
├→ spoke-1  (open)
│ └→ collector  (open) ◀─┐
├→ spoke-2  (open) ──────┤
├→ spoke-3  (open) ──────┤
└→ spoke-4  (open) ──────┘

Left side shows fan-out: hub has four children. Right side shows fan-in: all four spokes converge on collector. The ◀ arrowhead marks the target. One tree edge on the left, the rest are arcs on the right.
